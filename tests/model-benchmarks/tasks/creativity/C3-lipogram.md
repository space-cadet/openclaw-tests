# Task C3: Constraint Writing — Lipogram

## Difficulty: Creative — Constraint-Based

### Prompt
Write a coherent paragraph of at least 50 words that describes a sunset over the ocean, WITHOUT using the letter 'e' anywhere in the text (including the word "the").

### Requirements
1. At least 50 words
2. No letter 'e' or 'E' anywhere
3. Must describe a sunset over the ocean
4. Must be grammatically coherent and meaningful

### Scoring
1. **Constraint compliance** (pass/fail): Zero 'e's in output
2. **Length** (0-10): 50+ words = 10, 40-49 = 8, 30-39 = 6, <30 = 4
3. **Coherence** (0-10): Grammatical, meaningful description
4. **Imagery** (0-10): Vivid, evocative language
5. **Creativity** (0-10): Interesting word choices to avoid 'e'

Max: 40 points

### Output Format
Write the paragraph, then a word count and self-assessment.

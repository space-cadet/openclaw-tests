# Task C1: Alternate Uses Test (AUT)

## Difficulty: Creative — Divergent Thinking

### Prompt
"List 10 unusual or creative uses for a common brick. Think beyond the obvious (building, paperweight). Go for novelty, practicality, and variety."

### Scoring Criteria (auto + manual)
1. **Fluency** (quantity): How many valid uses listed (max 10)
2. **Flexibility** (categories): How many distinct categories (e.g., art, tool, furniture, garden, play)
3. **Originality** (novelty): Rarity of ideas vs common answers
   - Common: paperweight, doorstop, weapon
   - Uncommon: bookend, garden edging, fire pit liner
   - Novel: musical instrument, thermal mass for cooking, mold for casting

### Evaluation
- Score = (fluency × 1) + (flexibility × 2) + (originality × 3)
- Max theoretical: 10 + (5 categories × 2) + (10 novel × 3) = 50

### Output Format
Return a numbered list. Briefly explain each use in 1 sentence.

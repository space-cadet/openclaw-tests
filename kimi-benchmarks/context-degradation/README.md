# Kimi/OpenClaw Context Degradation

This directory records long-lived OpenClaw sessions in which Kimi tool calls
become unavailable while ordinary conversation continues.

## Reports

- [OpenClaw/Kimi tool degradation report](openclaw-kimi-tool-degradation.md)

The report is an evidence record, not a claim that one mechanism has been
proven. Raw transcripts, private paths, account identifiers, and credentials
must not be committed here.

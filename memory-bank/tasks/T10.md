## Description

## Acceptance Criteria

- [ ] Direct reports and SQLite reports agree on the same input files.
- [ ] Documented command flags match the actual CLI.
- [ ] Tests cover providers, gzip files, aliases, caches, and timezone boundaries.

## Implementation Details

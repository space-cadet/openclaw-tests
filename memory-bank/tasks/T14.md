## Task Specifications

### T2: Pivot Reaction Force
> A uniform rod of mass m and length L is pivoted at one end and released from rest in horizontal position. Find the reaction force at the pivot when the rod passes through the vertical position.

**Correct answer:** R = 5mg/2  
**Trap:** Most jump to F = mg or use energy sloppily without separating translational and rotational dynamics.

**Scoring rubric:**
- 40% — Correct final answer (within symbolic tolerance)
- 30% — Correct approach (energy + dynamics, not just F=ma)
- 20% — Identifies the trap (explains why F ≠ mg)
- 10% — Clean derivation (no logical gaps)

### T3: Markov Chain Asymmetry
> You flip a fair coin until you see either HT or TT. Which sequence appears first on average? What's the expected number of flips for each?

**Correct answer:** E[HT] = 4 flips, E[TT] = 3 flips  
**Trap:** They look symmetric but aren't. Low thinking assumes symmetry; high thinking builds the state machine.

**Scoring rubric:**
- 40% — Correct values for both expectations
- 30% — State machine / Markov chain approach
- 20% — Explains why the asymmetry exists
- 10% — Clean derivation

### T4: Async Closure Bug
```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
```
> Explain the output and fix it. Then: what if we change `var` to `let`?

**Trap:** Classic closure-in-loop. Follow-up tests block scoping vs closure capture depth.

**Scoring rubric:**
- 40% — Correct output prediction
- 30% — Correct fix (IIFE or `let`)
- 20% — Explains `let` behavior correctly
- 10% — Edge cases (e.g., what about `const` in loop head?)

### T5: Ramsey Planner on Graph
> You have a directed graph representing a supply chain. Each node has production function f(k) = k^α. Allocate capital across nodes to maximize total discounted utility over T time steps, with depreciation δ and discount factor β. Derive the Bellman equation and describe optimal policy structure.

**Trap:** Low thinking writes generic Bellman. Max thinking recognizes network structure, decentralized vs centralized solutions, computational complexity.

**Scoring rubric:**
- 40% — Correct Bellman equation
- 30% — Network structure insight
- 20% — Policy insight (decentralized vs centralized)
- 10% — Computational complexity discussion

## Protocol

### Per-Task Run
1. Launch 5 subagents in parallel (low/medium/high/xhigh/max)
2. Each receives identical task prompt
3. Record: runtime, input tokens, output tokens, score, self-corrections
4. Blind scoring: evaluate outputs without knowing which level produced them

### Total Runs
5 tasks × 5 levels = **25 subagents**
